# Answer Evaluation Rubric

Use this rubric when in "Answer Coaching Mode" to evaluate the candidate's responses.

---

## Scoring Dimensions

Each answer is evaluated on 4 dimensions, each scored 1-5:

### 1. Completeness (完整度)
| Score | Criteria |
|---|---|
| 1 | Misses the core point, answer is off-topic |
| 2 | Covers surface level only, missing key components |
| 3 | Covers main points but misses important details |
| 4 | Comprehensive, covers most relevant aspects |
| 5 | Thorough, covers all aspects including edge cases |

### 2. Depth (深度)
| Score | Criteria |
|---|---|
| 1 | Pure memorization, no understanding shown |
| 2 | Can describe "what" but not "why" |
| 3 | Explains reasoning but lacks nuance |
| 4 | Shows deep understanding, discusses trade-offs |
| 5 | Expert-level insight, challenges assumptions, proposes improvements |

### 3. Clarity (表达清晰度)
| Score | Criteria |
|---|---|
| 1 | Disorganized, hard to follow |
| 2 | Somewhat structured but jumps around |
| 3 | Logical flow, adequate structure |
| 4 | Well-structured, uses examples effectively |
| 5 | Exceptional communication, concise yet complete, uses analogies |

### 4. Authenticity (真实度)
| Score | Criteria |
|---|---|
| 1 | Sounds rehearsed or fabricated |
| 2 | Mostly generic, hard to tell if this was their work |
| 3 | Some personal details, plausible ownership |
| 4 | Clearly based on real experience, specific details |
| 5 | Deeply authentic, can improvise follow-ups naturally |

---

## Feedback Template

For each answer, provide feedback in this format:

```markdown
### 评价

| 维度 | 得分 | 评语 |
|---|---|---|
| 完整度 | X/5 | [Specific feedback] |
| 深度 | X/5 | [Specific feedback] |
| 表达 | X/5 | [Specific feedback] |
| 真实度 | X/5 | [Specific feedback] |
| **总分** | **X/20** | |

### 优点
- [What was good about this answer]

### 改进建议
- [What's missing or could be better]

### 参考回答
[An improved version of the answer, written as the candidate should say it]
```

---

## Common Answer Anti-Patterns

Watch for these and call them out in feedback:

| Anti-Pattern | Example | Fix |
|---|---|---|
| 背书式回答 | Reciting textbook definitions without context | Add personal experience and specific examples |
| 模糊贡献 | "我负责模型训练" | Specify: which model, what data, what metric, what result |
| 无法追问 | Can't answer follow-up about their own project | Prepare deeper layers for each project claim |
| 指标堆砌 | "accuracy 99.2%" without explaining evaluation setup | Explain dataset, split, baseline, significance |
| 技术名词堆砌 | Lists technologies without explaining integration | Explain how components connect and why chosen |

## Scoring Guide

| Total Score | Level | Feedback Tone |
|---|---|---|
| 16-20 | Strong | Highlight strengths, suggest minor refinements |
| 11-15 | Acceptable | Point out gaps, suggest practice areas |
| 6-10 | Needs Work | Detailed coaching needed, suggest rewriting answer |
| 4-5 | Weak | Recommend fundamental review of this topic |
