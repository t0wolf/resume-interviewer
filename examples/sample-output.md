## 二、技术深度 (Technical Deep-Dive)

### Q3. 你提到使用 LoRA 对 Qwen2-VL-7B 进行微调。LoRA 的核心原理是什么？为什么选择 LoRA 而不是全量微调？
**考察点：** 对参数高效微调的理解深度
**追问：** LoRA 的秩 r 是怎么选的？r=8 和 r=64 在你的任务上效果差多少？有没有做过对比实验？

### Q4. DPO 和 RLHF 都是偏好对齐方法。它们的核心区别是什么？你在什么场景下选择了 DPO？
**考察点：** 对齐方法的工程选型能力
**追问：** DPO 的 loss function 是怎样的？它有什么已知的局限性？如果 reward model 训练得不好，DPO 能避免这个问题吗？

### Q5. 你使用了 QLoRA 的 4-bit 量化来微调模型。4-bit 量化会带来什么精度损失？你是怎么评估的？
**考察点：** 量化技术的工程理解
**追问：** NF4 和 INT4 有什么区别？为什么 QLoRA 选择了 NF4？

### Q6. 你提到了 Swin Transformer 和 ViT。能解释一下 Swin 的 window attention 机制吗？相比 ViT 的全局 attention 有什么优势？
**考察点：** 视觉骨干网络的理解深度
**追问：** shifted window 具体是怎么实现的？它解决了什么问题？

### Q7. 你在评测中横向对比了 9+ 款 VLM。评测指标中 Token 消耗和推理速度是怎么测量的？不同模型的 prompt 格式差异会影响结果公平性吗？
**考察点：** 评测方法论的严谨性
**追问：** 有没有考虑过用 LLM-as-Judge 来评估生成质量？这种方法有什么优劣？

### Q8. vLLM 的 PagedAttention 机制解决了什么问题？能简单解释一下它的工作原理吗？
**考察点：** 推理加速技术理解
**追问：** 如果 KV cache 内存不够用，除了 PagedAttention 还有什么优化方案？

### Q9. 你提到使用了梯度累积优化。在什么场景下需要梯度累积？它和增大 batch size 在数学上是等价的吗？
**考察点：** 训练细节的理解
**追问：** 梯度累积时，BatchNorm 的行为会有什么不同？你的项目中是怎么处理的？

## 三、项目深度 (Project Walkthrough)

### Q10. [GraphRAG 项目] 你使用 LightRAG 构建了知识图谱，包含 17+ 实体和 13+ 关系。这些实体和关系是怎么提取的？用的什么模型？
**考察点：** 知识图谱构建的工程细节
**追问：** 实体消歧是怎么做的？如果同一个设备在不同文档中用了不同名称，怎么合并？

### Q11. [GraphRAG 项目] 你提到"工业参数的 100% 精准召回"。这个指标是怎么定义和测量的？测试集有多大？
**考察点：** 对自己声称指标的验证能力
**追问：** 100% 召回率在实际生产环境中可能吗？有没有可能是测试集太简单或者有数据泄露？

### Q12. [GraphRAG 项目] Hybrid（向量 + 路径索引）检索模式的融合策略是什么？如果两种检索返回了矛盾的结果，怎么处理？
**考察点：** RAG 系统设计能力
**追问：** 向量检索和图检索各自的 latency 是多少？是串行还是并行？

### Q13. [草块病害项目] ResNet34 分类准确率 99.2%。数据集有多大？类别是否均衡？有没有用过 confusion matrix 分析哪些类别容易混淆？
**考察点：** 对分类任务评估的严谨性
**追问：** 如果新增一种病害类别，需要重新训练整个模型吗？增量学习了解吗？

### Q14. [草块病害项目] 你提出"局部裁割 + 红点标记"方案来解决 VLM 空间定位幻觉问题。能详细解释一下这个方案吗？
**考察点：** 创新性思维和问题解决能力
**追问：** 为什么红点标记比直接给坐标更有效？有没有量化对比过两种方案的效果？

### Q15. [DPO 偏好对齐] 你构建了"精准像素坐标 (Chosen)" vs "定性方位描述 (Rejected)"的数据集。数据集是怎么构建的？有多少条？质量怎么保证？
**考察点：** 数据工程能力
**追问：** 如果 Chosen 和 Rejected 的差异太明显，模型可能学到的是表面模式而不是真正的空间理解。你怎么避免这个问题？
